# 청라스마트러닝센터 일일탐구일지

## 사용 방법

1. 기본 정보에 이름·날짜와 STEAM-L1/L2 → 그룹 → 교육 주제를 선택합니다. 총 24개 교육 주제를 제공합니다.
2. 오늘의 탐구에서 활동 단계, 목표, 예상과 이유를 작성하고 준비물 10종을 체크합니다.
3. 과정과 결과, 학습내용 정리를 작성합니다. 바꾼 조건·같게 유지한 조건·다음 탐구 계획은 제외했습니다.
4. 학습 정리에서 그림파일과 일반 파일을 첨부할 수 있습니다. 그림 미리보기, 파일 저장, 삭제를 지원합니다. 파일당 10MB, 전체 30MB, 최대 30개입니다.
5. 나의 학습 모습에서 원하는 사진칸 안의 카메라로 촬영을 누릅니다. 노트북 카메라 권한을 허용한 뒤 사진 찍기를 누르면 선택한 칸에 저장됩니다. 4칸 모두 채운 뒤에도 다시 촬영할 수 있습니다. 사진 파일 선택은 빈 칸부터 추가합니다.
6. 오른쪽 위 JPEG 저장을 누르면 일지 전체, 첨부 그림, 일반 파일 이름, 2×2 사진과 설명이 한 장의 이미지로 저장됩니다. 기본 너비는 1200px이며 내용에 맞춰 높이가 늘어납니다.

## JPEG 파일 이름과 저장 위치

이름과 날짜를 입력해야 저장할 수 있습니다. 파일 이름 예: `2026-09-10_홍길동.jpg`.

저장 위치 선택 기능을 지원하는 브라우저는 바탕화면을 시작 위치로 제안하는 저장 창을 표시합니다. 원하는 폴더가 바탕화면인지 확인한 뒤 저장하세요. 지원하지 않는 브라우저나 인앱 브라우저는 일반 다운로드로 저장합니다. 이 경우 브라우저 다운로드 설정에서 바탕화면을 선택하거나 다운로드된 이미지를 바탕화면으로 옮기세요. 웹페이지가 모든 브라우저에서 바탕화면으로 저장 위치를 강제로 지정할 수는 없습니다.

JPEG에는 일반 첨부파일의 내용이 포함되지 않습니다. 원본 파일까지 보관하려면 내보내기로 JSON 일지 파일을 저장하세요. 가져오기로 다시 편집할 수 있습니다. 첨부 그림은 JPEG 출력과 화면 미리보기에서 크기를 줄이지만 원본 파일도 함께 보관합니다.

## 실행과 보관

로컬 서버: Node.js가 설치된 환경에서 `npm run dev` 실행 후 http://127.0.0.1:4173 접속. 카메라는 HTTPS 또는 localhost와 브라우저 카메라 권한이 필요합니다.

내용·사진·첨부파일은 이 기기의 브라우저 저장소에 자동 저장됩니다. 기존 일지도 불러옵니다. 다른 기기로 자동 동기화되지 않으며, 주소나 브라우저를 바꿀 때는 내보내기/가져오기를 사용하세요. 공용 기기에서는 보관 후 새 일지를 눌러 주세요. 저장 오류가 표시되면 내보내기로 보관하세요.

기존 발명 템플릿은 original-template 폴더에 보관되어 있습니다.

## 검증

교육과정 및 백업 데이터 검증, 10종 체크박스 초기화, 사진칸 유지, 첨부파일 복원, JPEG 파일명과 한글 보고서 이미지 생성을 검사했습니다. 이미지 렌더링 검사는 개발 환경의 Canvas 구현을 사용합니다. 실제 기기 카메라와 브라우저 저장 창의 동작은 사용 환경에 따라 확인이 필요합니다.

## 음성 입력

텍스트 입력칸 옆의 음성 입력 버튼을 누르고 마이크 권한을 허용하면 한국어로 받아씁니다. 기존 글은 유지하며 커서 위치에 확정된 인식 결과를 넣습니다. 다시 누르면 종료합니다. 화면 이동이나 직접 타이핑 시에도 종료합니다. 사진 설명처럼 나중에 생기는 입력칸에도 버튼이 표시됩니다. 기본정보와 측정 기록표에는 음성 입력 버튼이 표시되지 않습니다.

브라우저 음성 인식 지원과 인터넷 연결이 필요할 수 있습니다. 인앱 브라우저가 지원하지 않으면 Chrome 또는 Edge에서 같은 주소를 열어 주세요. 브라우저에 따라 음성이 해당 브라우저의 음성 인식 서비스로 전송될 수 있습니다.
